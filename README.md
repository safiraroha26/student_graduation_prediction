# Student Graduation Prediction

A machine learning project that predicts student graduation status
using Logistic Regression based on study hours, attendance,
assignment scores, and exam scores.

## Project Overview

This project applies supervised learning to predict whether a student
will pass or fail based on their academic and learning-related data.

The model is trained using Logistic Regression and evaluated using
accuracy, confusion matrix, and classification report.

## Dataset

The dataset contains the following features:

- Jam Belajar
- Kehadiran
- Nilai Tugas
- Nilai Ujian

Target variable:

- Status Lulus
  - 0 = Tidak Lulus
  - 1 = Lulus

## Machine Learning Process

The project includes:

- Data loading
- Data cleaning
- Feature selection
- Data splitting
- Logistic Regression
- Model evaluation
- New student prediction
- Probability prediction

## Model

### Logistic Regression

Logistic Regression is used as a classification algorithm to predict
the student's graduation status based on the selected features.

## Evaluation

The model is evaluated using:

- Accuracy
- Confusion Matrix
- Classification Report

## Prediction

The model can also predict the graduation status of a new student
based on:

- Study hours
- Attendance
- Assignment score
- Exam score

The model also provides the probability of each predicted class.
